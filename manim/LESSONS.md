## 渲染前检查清单（每次开工照着过一遍）

- [ ] Box 状态是 running（不是就唤醒一次；失败则等，不硬试）
- [ ] Manim / ffmpeg / LaTeX（pdflatex、dvisvgm）/ Noto Sans CJK SC 都在
- [ ] 代码里分数一律 MathTex，不许出现斜杠写法（"3/5" 只能出现在 Text 之外的纯数字场景，见下）
- [ ] 步骤标题与算式组留出 0.9 个单位以上净空
- [ ] 粉色 #FF6B9D 全片只表示"新增的那一段"，同一时刻只有一处粉色
- [ ] 字幕在底部安全区（距底部约 18% 高度），每行不超过 16 个字
- [ ] 逐字稿通读一遍：分数中文读法按口语习惯（90/100 是"百分之九十"，不是"九十分之一百"）
- [ ] 主体内容在画面 15%~70% 高度区，右侧 12% 不放文字，顶部 8% 不放重要信息
- [ ] 渲染后抽 8 帧（2、8、16、24、33、38、45、52 秒）自检：无重叠、无出界、数字与验算一致

## Box 环境与操作教训

- Box 是全新 Ubuntu 24.04，第一次用要现装环境：`python3-venv`、`ffmpeg`、
  `texlive-latex-base` + `texlive-latex-recommended` + `texlive-fonts-recommended` +
  `texlive-latex-extra`（MathTex 要用 standalone.cls，没有它会报错） +
  `dvisvgm`、`fonts-noto-cjk`、`libcairo2-dev`、`libpango1.0-dev`、`python3-dev`
  （pycairo 编译要 Python 头文件，没有会失败）；
  再建 venv 装 `manim==0.22.1`。LaTeX 比较大，安装要 10~20 分钟。
- MCP 的 shell 调用约 45 秒超时：apt、pip、渲染一律 `nohup … > 日志 2>&1 &`
  放后台，再用短命令轮询日志；超时后先查状态，不要直接重跑。
- Box 闲置会休眠，唤醒一般几秒；官方只写"闲置就睡、唤醒约一秒"，
  没有公开具体是空闲几分钟后睡，不要编数字（2026-11-08 已查官网文章与文档，未找到）。
  实测办法：渲完后让 Box 空闲放着，每隔几分钟查一次状态，看何时变 hibernated。
- Box 闲置会休眠，唤醒一般几秒；但宿主机满了会报
  `Ensure failed: node at capacity, try again shortly`，状态变 failed，
  此时不要死磕，等一会儿再试，或让用户在门户 live 页手动唤醒。
- Box 内登录账号会被风控：2026-11-08 在 Box 的 Chrome 里登录提示
  `access is temporarily restricted`（疑似 GitHub），原因是 Box 出口为机房共享 IP。
  不要反复重试以免锁号；成片导出走免登录的文件站路线。
- MCP 没有二进制下载工具（`read_file` 只读文本、还截断长行），
  渲好的 mp4 拿不回来，只能走文件站中转或 Box 内登录 GitHub 上传。
- Box 直连 DNS 是坏的（getent 解析 github.com、google.com 均失败），
  但本地代理 127.0.0.1:3128 可用：SSH 走 Python CONNECT 转发脚本
  `/workspace/connect-proxy.py` + `~/.ssh/config` 里给 github.com 配
  `ProxyCommand python3 /workspace/connect-proxy.py %h %p`，git 直接走它；
  github.com 网页经代理仍 504（与当天 GitHub 波动一致），不影响 SSH 推送。
- 桌面截图传回来是 base64 文本，Box 端看不到拼图画面：视觉验收只能靠
  OCR + 像素比对 + 颜色计数，且拿上一版帧当基准比对会漏掉定格帧重叠
  （像素一致只证明"没变"，不证明"没错"）。本地 pull 后必须肉眼逐帧看。
- 代码进 Box 用 `write_file`（参数 JSON 用 Python 的 `json.dump` 生成，
  不要用 echo/heredoc 传代码，里面的反斜杠、引号和 $ 会坏掉）。
- MCP shell 不展开 `$`：命令里不要用 `$VAR`、`$!`、for 循环变量（会变空串，
  后台启动时 pid 打不出来也是这个原因），写全路径、逐条直写命令；
  查后台进程用 `ps aux | grep`，不要依赖 `$!`。
- 帧坐标：竖屏 1080×1920 用 frame 9×16；渲染命令
  `python -m manim render -qm -r 1080,1920 --format=mp4`，
  渲完用 `ffprobe` 核对分辨率/帧率/时长，再抽 8 帧拼图上屏截图验收。
