# 智能客服满意度 · Manim 讲解动画

3Blue1Brown 风格的数学讲解动画，使用 Manim Community Edition 渲染。

## 题目

> 某公司由于客服人数较少，满意度只有 3/5。后面引进了智能客服单独服务，满意度是原来的 6/5。现在采用智能客服与人工客服双重服务，满意度又提高了 1/4。那么现在的满意度是多少？

## 答案

**9/10**

```
3/5 × 6/5 = 18/25
18/25 × (1 + 1/4) = 18/25 × 5/4 = 90/100 = 9/10
```

交叉验算（化小数）：0.6 × 1.2 = 0.72，0.72 × 1.25 = 0.9 ✓

## 分镜表（6 幕）

| 幕 | 步骤 | 内容 |
|---|---|---|
| 1 | 第 1 步 · 看题目 | 5 格满意度条（3 格填充）+ 三条条件逐条入场 + 加粗问题句 |
| 2 | 第 2 步 · 建模型 | 链条图 [3/5] →(×6/5)→ [?] →(×(1+1/4))→ [?]，只建模不计算 |
| 3 ⭐ | 第 3 步 · 关键一跳 | 0~1 标尺上条生长：3/5→18/25→切出 1/4 粉块→9/10；点破句「单位「1」变了：这次的 1/4，是 18/25 的 1/4」 |
| 4 | 第 4 步 · 列式求解 | 算式逐行入场：3/5×6/5=18/25 → ×(1+1/4) → ×5/4 → 90/100 → 9/10；灰字带过化小数另法 |
| 5 | 第 5 步 · 代回验算 | 10 格条摆出 9/10 可数；逆向除回两条 ✓ + 合理性 ✓ |
| 6 | 答案卡 | 居中描边圆角框：灰字「答案」+ 黄色大字「现在的满意度是 9/10」 |

## 主线与关键一跳

- **主线讲法**：单位"1"连乘——把两句话翻译成两次放大（×6/5、×5/4），在 0~1 标尺上让满意度条真实生长，标尺全程不动
- **关键一跳**（第 3 幕）：「又提高 1/4」的单位"1"不是最初的 3/5，而是当下的 18/25
