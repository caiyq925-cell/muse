# Cloady 部署提示词（通用模板）

> 用法：把下面整段复制给任何 AI，只填输入区。已按 Cloady 官方文档核对过。
>
> 版本：v1（2026-11-09）。实例：xray 节点已用这套办法部署在工作区 cai（美西 usw1），免费 $0。

## 提示词正文（从这行开始复制）

你要在 Cloady 上部署一个应用，部署在已有的免费工作区里，不新建工作区、不绑卡、不付款。

==================== 输入区（只改这里） ====================
（必填）要部署的应用：名字和一句话用途，例如：个人博客 / 小 API / 机器人 / 代理节点
（必填）来源，四选一：
  - Docker 镜像：写镜像名，例如 ghcr.io/xtls/xray-core
  - GitHub 仓库：写仓库地址，构建用 Railpack 或仓库里的 Dockerfile
  - 上传文件夹：本地项目文件夹，里面要带 Dockerfile
  - 模板：写模板名，例如 WordPress / Postgres / n8n
（必填）容器内监听端口，例如：3000
（选填）环境变量：只写名字，值在 Cloady 面板里填，不要写进提示词（密码、密钥、token 一律不写）
（选填，默认 USW1）区域：免费档选 USW1（美西）；JPN1 是试用档、一个月到期，不选
（选填，默认自动域名）域名：用 Cloady 自动给的 xxx.cloady.io；自定义域名另外说
============================================================

硬约束（违反任何一条就停下报告）：
1. 全程不绑卡、不付款，结算必须是 $0.00/mo。出现 payment_required、绑卡、扣费、升级提示，立刻停下报告，不许填卡。
2. 免费档红线（整个工作区所有应用加起来）：0.5 vCPU、1GB 内存、5GB 磁盘。超任何一项，整个工作区开始计费，不是只收超出的部分。
3. 免费档月限额：出站流量 10GB（官方文档最新写法；2026-11-05 时是 15GB，以面板显示为准）、HTTP 请求 100 万次、CPU 4 小时、内存 360 GB-小时；单次构建 45 分钟超时会失败；每天最多部署 100 次。
4. 一个账号只有一个免费工作区，不要新建第二个工作区。已有工作区 cai，直接在里面建应用。
5. 区域：免费档选 USW1；JPN1 是试用档（一个月到期），不要选；部署页显示哪个区是免费档就以部署页为准。
6. 7 天无流量应用会暂停。长期不用的应用先停掉，省额度。

步骤：
1. 登录 cloady.com，进工作区 cai（cloady.com/w/cai），确认顶部显示 FREE、$0.00/mo。
2. 点 Deploy，选来源；Docker 镜像直接填镜像名；GitHub 仓库填地址；上传文件夹要带 Dockerfile；模板直接选。
3. 区域选 USW1，资源保持 0.5 vCPU、1GB、5GB，确认价格显示 $0.00/mo 再点部署。
4. 部署后核对：应用状态 RUNNING、域名能打开、日志无端口报错；记下域名和端口。
5. 交付：应用地址、区域、资源、月流量上限、怎么看用量（工作区/应用页 Overview 里看内存、CPU、流量）。

验收：域名能打开、状态 RUNNING、计费 $0、不绑卡。做不到就停下说清楚哪一步卡住了，不要编数字。
